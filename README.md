# 수강신청 플랜 B

수강신청에 실패한 분반을 제외하고, 남은 후보로 대안 시간표를 찾아 비교하는 웹서비스를 만들 계획이다.

## 기획 배경

원하는 분반을 신청하지 못하면 다른 분반의 수업 시간이 기존 시간표와 겹치는지 다시 확인해야 한다.
후보 강의를 미리 등록하고 선택할 수 없는 분반을 제외하면, 가능한 시간표를 빠르게 비교할 수 있도록 만들고 싶다.

## 구현할 기능

- 로그인한 사용자가 자신의 후보 강의를 등록·수정·삭제한다.
- 과목명, 분반, 학점, 요일과 수업 시간을 입력한다.
- 수강신청에 실패한 분반을 선택 불가로 표시한다.
- 선택 불가 분반을 제외한 뒤, 수업 시간이 서로 겹치지 않는 조합을 찾는다.
- 공강일 우선 또는 수업 사이 빈 시간 최소화 기준으로 결과를 비교한다.
- 마음에 드는 시간표를 저장하고 다시 불러온다.
- 시간표 변경을 취소하거나 변경 전 상태로 복원한다.

## 초기 구현 범위

- 원하는 과목은 최대 6개, 과목별 후보 분반은 최대 3개로 제한한다.
- 선택한 과목마다 한 분반씩 포함하는 조합을 만든다.
- 조건을 만족하는 대안 시간표를 최대 10개까지 보여준다.
- 강의 정보와 신청 실패 여부는 사용자가 직접 입력한다.
- 실제 수강신청을 대신 수행하는 기능은 포함하지 않는다.

## 사용할 기술

- 화면: React, JavaScript
- 로그인: Firebase Authentication
- 데이터 저장: Cloud Firestore
- 배포: JCloud

## 설계 및 검증 계획

서로 다른 디자인 패턴 8종의 적용 위치와 역할을 설계하고, 실제 기능에서 작동하는지 확인할 예정이다.
시간 충돌 검사, 선택 불가 분반 제외, 시간표 정렬, 변경 취소를 테스트한다.
저장한 내용이 유지되는지와 다른 사용자의 데이터에 접근할 수 없는지도 확인한다.
